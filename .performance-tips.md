# Performance Optimization Guide

## Deployed vs Local Performance

### Current Optimizations Applied

1. **API Timeouts Extended**
   - All billing and admin routes now have `maxDuration = 26s` (Netlify free tier max)
   - MongoDB connection timeouts increased for deployment latency
   - Better handling of cold starts

2. **MongoDB Connection Pooling**
   - Connection pooling with maxPoolSize=10
   - Increased timeouts: serverSelection=10s, connect=15s, socket=60s
   - Retry logic for transient failures

3. **Caching Strategy**
   - Static assets: 1 year cache
   - API responses: no-cache (for real-time data)
   - GitHub API: 5-minute cache
   - Images: 30-day cache

4. **Network Optimization**
   - PWA enabled for offline capability
   - Service worker caching for repeat visits
   - Prefetch critical resources

### Known Limitations on Free Tier

**Netlify Free Tier:**
- Function timeout: Max 26 seconds (vs unlimited locally)
- Cold starts: ~2-5 seconds for first request
- No dedicated resources (shared infrastructure)

**Solutions for Paid Users:**

1. **Upgrade to Netlify Pro ($19/month)**
   - Function timeout: 60 seconds
   - Background functions: 15 minutes
   - Better performance SLA

2. **Use Vercel Pro ($20/month)**
   - Function timeout: 60 seconds (Hobby: 10s)
   - Edge functions for faster responses
   - Better global CDN

3. **MongoDB Atlas M10+ Cluster**
   - Dedicated resources
   - Better connection pooling
   - Auto-scaling

### Monitoring

Check deployment performance:
```bash
# Monitor function execution time
netlify functions:list

# Check MongoDB connection
npm run test:mongodb

# Test API response time
curl -w "@curl-format.txt" https://your-app.netlify.app/api/health
```

### Tips for Users

1. **First load is slower** - Cold start penalty (2-5s)
2. **Subsequent requests are faster** - Connection pooling + cache
3. **Use PWA** - Install as app for better offline performance
4. **Paid tier recommended** for production workloads
